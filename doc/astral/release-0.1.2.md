# Astral Client 0.1.2

This checkpoint matches the locally installed vanilla-only achievement build and equipment-layer UI. Later work extending reward coverage is excluded.

Major features: mouse controls with retained hotkeys; HUD and minimap; equipment layers and distinct weapon holders; workstation management; an illustrated vanilla achievement interface and reward bank for supported goals. There are 211 vanilla achievement images, zero enabled expansion goals and six reward mappings.

Source reconstruction uses the installed data snapshot and the recorded post-install source delta. The staged Linux executable passed strict data checks and 565 assertions across 9 focused bank, shield and shelving tests. Earlier equipment validation passed 19 assertions across 2 cases plus representative native drag/drop, holster and save/reload checks. These checks do not establish exhaustive gameplay acceptance.

Linux and Windows full packages include updaters. This release changes game data: use the full distribution; older executable-only update archives are insufficient. Astral Tileset 0.1.25 is an independent optional download. User profiles are excluded from all packages.
