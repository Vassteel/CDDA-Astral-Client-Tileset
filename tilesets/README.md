# Astral Tileset

The art package is independent from Astral Client. Copy the `Astral` folder into a compatible CDDA installation's `gfx` directory and select Astral in Graphics options. It contains its own UltiCa fallback; no client executable or settings are included.

The packaged version is 0.1.5. Static atlas/configuration checks passed; the newly detailed autumn olive exports still need gameplay visual acceptance. See the artwork attribution, license, manifest and progress files inside `Astral`.

[Art-only download](https://github.com/Vassteel/CDDA-Astral-Client-Tileset/releases/tag/tileset-v0.1.5)
