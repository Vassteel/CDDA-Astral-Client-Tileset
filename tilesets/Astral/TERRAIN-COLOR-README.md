# Astral terrain and color playtest

Adds 41 natural terrain types with all 16 connection masks and three center alternatives per material set. Uses explicit snow-free material mappings in all four seasons; gameplay ice states have separate thin/thick and shallow/deep art. Seasonal grass underlays follow the approved color pass. Shared indoor/underground terrain receives no baked outdoor snow.

Includes the approved color pass on 600 flora sprite variants, 16 ordinary grass alternatives, and 140 matching underlay cells. Preserves installed creature/item playtest additions and unrelated mappings. UI and client code are outside this package.

39 terrain types still need source art or review. New terrain passes static index, connection and offline composition checks; live gameplay acceptance remains pending. Material reuse and color derivatives are recorded separately from new drawings. This is a local playtest update, not a published release.
