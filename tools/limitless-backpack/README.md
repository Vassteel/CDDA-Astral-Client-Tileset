# Limitless backpack

A weightless backpack with unlimited storage, no weight or bulk from its
contents, zero encumbrance, and spoilage prevention. Food remains preserved
inside nested containers too. Uses the installed tileset's backpack sprite.
Liquids should remain in bottles or other containers.

Use the modified **CDDA Tileset Picker** launcher for unlimited capacity.
The Steam executable can recognize the compatibility version of the item,
which preserves weight and spoilage benefits but has a large finite capacity.

Item/mod ID: `limitless_backpack`.

The character save is backed up before adding and equipping one backpack.
Other inventory, character values, position, and game time are preserved.
